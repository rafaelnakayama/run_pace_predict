# run_pace_predict

Projeto da disciplina de Estatistica II

## Ambiente virtual

Este projeto utiliza uv como gerenciador de pacotes, instale-o clicando [aqui](https://docs.astral.sh/uv/getting-started/installation/)

quando o uv estiver instalado basta rodar o comando abaixo dentro do repositorio para baixar as dependencias e criar o ambiente virtual.

```
uv sync
```
